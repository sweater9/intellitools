AI Glossary A–Z

Plain-English definitions of 64 AI terms, each linking to the deeper explanation where one exists.

ABCDEFGHIJKLMNOPQRSTVZ

A

Agent (AI agent)
A system in which a model pursues a goal by repeatedly choosing actions, calling tools and reading the results until it finishes or hits a limit.
Learn more: What are AI Agents? · AI Agent vs Chatbot vs Assistant: What's the Difference?
See also: Tool · Agentic workflow
Agentic workflow
A designed process that combines model calls, tools, checks and sometimes humans along a path the developer defines, as opposed to a model freely choosing every step.
Learn more: Agentic Workflows: Patterns for Reliable AI Automation
See also: Agent
AI (Artificial Intelligence)
The broad field of building software that performs tasks normally associated with human judgement, such as perception, language and decision-making.
Learn more: What is Artificial Intelligence?
See also: Machine learning · Deep learning
Alignment
Work to make AI systems behave in line with human intentions and values, including being helpful, honest and safe. Training steps such as instruction tuning and preference tuning contribute to it.
Learn more: What is a Large Language Model (LLM)?
See also: Instruction tuning · RLHF
Approximate nearest neighbour (ANN)
A family of search methods that quickly find vectors that are very likely, though not guaranteed, to be the closest to a query. Used by vector databases to stay fast at scale.
Learn more: What is a Vector Database?
See also: Vector database
Attention
The mechanism in a transformer that lets each token weigh how relevant every other token is when building its representation.
Learn more: What is a Transformer? (Attention Explained)
See also: Transformer

B

Benchmark
A standard test used to compare models on a defined task. Useful for rough comparison, but not a substitute for testing on your own use case.
Learn more: How to Evaluate AI Systems and Outputs
See also: Evals

C

Chain of thought
A prompting technique in which the model is encouraged to work through intermediate reasoning steps before giving its answer. Its usefulness varies by model and task.
Learn more: Prompt Engineering: How to Write Better AI Prompts
See also: Prompt
Chatbot
Software that converses with users. Modern chatbots are usually powered by LLMs; the word says little about whether the system can take actions.
Learn more: AI Agent vs Chatbot vs Assistant: What's the Difference?
See also: Agent
Chunking
Splitting documents into smaller passages so each can be embedded and retrieved on its own, as in RAG.
Learn more: Chunking: How to Split Documents for RAG · What is RAG (Retrieval-Augmented Generation)?
See also: Embedding · RAG
Context window (context length)
The maximum amount of text, measured in tokens, a model can consider in one request, covering instructions, conversation, documents and the reply.
Learn more: What is a Context Window? · What are Tokens in AI?
See also: Token
Cosine similarity
A measure of how closely two vectors point in the same direction. It is widely used to compare embeddings: values near 1 mean very similar, near 0 mean unrelated.
Learn more: What are Embeddings in AI?
See also: Embedding · Vector

D

Deep learning
Machine learning that uses neural networks with many layers. It underlies most modern vision, speech and language models.
Learn more: What is Artificial Intelligence?
See also: Machine learning · Neural network
Diffusion model
A generative model, common in image generation, that starts from random noise and refines it step by step into content matching a prompt.
Learn more: What is Generative AI?
See also: Generative AI

E

Embedding
A list of numbers (a vector) that represents the meaning of content so that similar items are close together. Basis of semantic search and RAG.
Learn more: What are Embeddings in AI? · What is a Vector Database?
See also: Vector · Semantic search
Evals (evaluations)
Structured tests that measure how well an AI system performs on tasks you care about, using test cases, graders and tracked scores.
Learn more: How to Evaluate AI Systems and Outputs
See also: Benchmark

F

Few-shot prompting
Including a small number of example inputs and outputs in the prompt to show the model the pattern you want. Zero-shot means giving no examples.
Learn more: Prompt Engineering: How to Write Better AI Prompts
See also: Zero-shot prompting · Prompt
Fine-tuning
Further training a pre-trained model on your own examples so it adopts a consistent behaviour, format or skill.
Learn more: What is Fine-Tuning an AI Model? · RAG vs Fine-Tuning: Which Should You Use?
See also: LoRA · RAG
Foundation model
A large model trained on broad data that can be adapted to many tasks. Large language models are the best-known example.
Learn more: What is a Large Language Model (LLM)? · What is Generative AI?
See also: LLM
Function calling (tool calling)
A model-API feature in which the model returns a structured request to run a named function with arguments. Your code runs it and returns the result.
Learn more: Function Calling (Tool Calling) Explained · Function Calling vs MCP
See also: Tool · MCP

G

Generative AI
AI that produces new content such as text, images, audio, video or code.
Learn more: What is Generative AI?
See also: LLM · Diffusion model
Grounding
Tying a model's answer to supplied source material or tool results so claims can be traced and checked.
Learn more: How to Reduce AI Hallucinations · What is RAG (Retrieval-Augmented Generation)?
See also: RAG · Hallucination
Guardrails
Checks and limits around an AI system, such as input filters, output validation, permission limits and human approvals, that reduce harmful or unwanted behaviour.
Learn more: AI Privacy and Security: What to Know Before You Paste Data · What is Prompt Injection?
See also: Prompt injection

H

Hallucination
Fluent, confident model output that is false, unsupported by the sources, or invented, such as fake citations or facts.
Learn more: AI Hallucinations: Why Models Make Things Up · How to Reduce AI Hallucinations
See also: Grounding
Human in the loop
A design in which a person reviews or approves AI output or actions at defined points, especially before high-impact or irreversible steps.
Learn more: Agentic Workflows: Patterns for Reliable AI Automation · What are AI Agents?
See also: Agentic workflow
Hybrid search
Combining keyword search with vector similarity (often plus metadata filters), so exact terms and meaning are both covered.
Learn more: Vector Database vs Traditional Database · What is RAG (Retrieval-Augmented Generation)?
See also: Semantic search

I

Inference
Running a trained model to produce output for new input, as opposed to training it.
Learn more: What is a Large Language Model (LLM)? · What is Local AI? Running Models on Your Own Device
See also: Training
Instruction tuning
Additional training that teaches a pre-trained model to follow instructions and respond helpfully, turning a text predictor into an assistant.
Learn more: What is a Large Language Model (LLM)? · What is Fine-Tuning an AI Model?
See also: Fine-tuning · RLHF

J

Jailbreak
An attempt to get a model to break its safety rules through crafted input. Related to, but distinct from, prompt injection.
Learn more: What is Prompt Injection?
See also: Prompt injection

K

Knowledge cut-off
The point after which a model's training data contains no information. Later events are unknown to it unless supplied via the prompt, search or tools.
Learn more: What is a Large Language Model (LLM)?
See also: LLM

L

LLM (Large Language Model)
A very large neural network trained on text to predict the next token, enabling writing, summarising, translation, question answering and code generation.
Learn more: What is a Large Language Model (LLM)? · What is a Transformer? (Attention Explained)
See also: Token · Transformer
Local AI
Running models on hardware you control instead of a hosted service, so data need not leave your device.
Learn more: What is Local AI? Running Models on Your Own Device · Local AI vs Cloud AI: Privacy, Cost, Capability
See also: Open weights · Quantisation
LoRA (low-rank adaptation)
A parameter-efficient fine-tuning method that trains small add-on matrices while the original model stays frozen, greatly reducing training cost.
Learn more: What is Fine-Tuning an AI Model?
See also: Fine-tuning

M

Machine learning
The part of AI in which systems learn patterns from data rather than following hand-written rules.
Learn more: What is Artificial Intelligence?
See also: Deep learning · Training
MCP (Model Context Protocol)
An open protocol for connecting AI applications to external tools, data and prompts through servers that clients can discover and call.
Learn more: What is MCP (Model Context Protocol)? · MCP Servers and Clients: Roles, Transports and Setup · MCP vs API: What's the Difference?
See also: MCP server · MCP client · Tool
MCP client
The component inside an AI host application that holds a connection to one MCP server and relays requests and results.
Learn more: MCP Servers and Clients: Roles, Transports and Setup
See also: MCP · MCP server
MCP server
A program that exposes tools, resources and prompts to MCP clients, often wrapping an existing API, database or file system.
Learn more: MCP Servers and Clients: Roles, Transports and Setup
See also: MCP · MCP client
Memory (agent)
Information a system stores outside the model and re-inserts into the prompt, such as recent messages, summaries and durable facts, because models themselves retain nothing between requests.
Learn more: Agent Memory: Short-Term, Long-Term and Beyond
See also: Context window
Multi-agent system
A setup in which several model-driven agents with distinct roles or contexts cooperate on a larger task.
Learn more: Multi-Agent Systems Explained
See also: Agent
Multimodal
Able to handle more than one type of data, such as text together with images or audio.
Learn more: What is Multimodal AI?
See also: Generative AI

N

Neural network
A model made of layers of simple connected units whose strengths (parameters) are adjusted during training. The basis of deep learning.
Learn more: What is Artificial Intelligence? · What is a Transformer? (Attention Explained)
See also: Deep learning · Parameters

O

Open weights
Models whose trained parameters are published for download and local use, subject to the licence. Not always the same as fully open source.
Learn more: What is Local AI? Running Models on Your Own Device
See also: Local AI
Overfitting
When a model or prompt works well on the examples used to build it but poorly on new cases. Held-out test data helps detect it.
Learn more: How to Evaluate AI Systems and Outputs · What is Fine-Tuning an AI Model?
See also: Evals

P

Parameters (weights)
The numbers inside a model that are adjusted during training and determine its behaviour. Model size is often quoted as a parameter count.
Learn more: What is a Large Language Model (LLM)?
See also: Neural network · Training
Pre-training
The initial, large-scale training stage in which a model learns general patterns from broad data before any specialised adaptation.
Learn more: What is a Large Language Model (LLM)? · What is Fine-Tuning an AI Model?
See also: Fine-tuning · Training
Prompt
The input given to a model: instructions, context, examples and the user's request.
Learn more: Prompt Engineering: How to Write Better AI Prompts · Common Prompting Mistakes (and How to Fix Them)
See also: System prompt
Prompt injection
An attack where text supplied to a model, directly or hidden in content it reads, tries to override the developer's instructions.
Learn more: What is Prompt Injection?
See also: Guardrails · Jailbreak

Q

Quantisation
Storing a model's parameters at lower numeric precision to cut memory use, usually at some cost in quality.
Learn more: What is Local AI? Running Models on Your Own Device
See also: Local AI · Parameters

R

RAG (Retrieval-Augmented Generation)
Retrieving relevant passages from your data and giving them to a model so its answer is based on that material.
Learn more: What is RAG (Retrieval-Augmented Generation)? · RAG vs Fine-Tuning: Which Should You Use?
See also: Embedding · Chunking · Vector database
Reranking
A second, more precise scoring step that reorders retrieved candidates before they are given to the model.
Learn more: What is RAG (Retrieval-Augmented Generation)?
See also: RAG
RLHF (reinforcement learning from human feedback)
A training approach that uses human preference judgements to steer a model towards responses people rate as better.
Learn more: What is Fine-Tuning an AI Model? · What is a Large Language Model (LLM)?
See also: Instruction tuning · Alignment

S

Sampling
The step where the next token is chosen from the model's probabilities. Settings such as temperature control how predictable or varied the choice is.
Learn more: What is a Large Language Model (LLM)?
See also: Temperature · Token
Semantic search
Searching by meaning rather than exact words, usually by comparing embeddings.
Learn more: What are Embeddings in AI? · What is a Vector Database?
See also: Embedding · Hybrid search
Structured output
Model output constrained to a defined format, such as JSON matching a schema, so software can use it directly.
Learn more: Function Calling (Tool Calling) Explained · Prompt Engineering: How to Write Better AI Prompts
See also: Function calling
System prompt
Standing instructions from the developer that define a model's role, rules and format across a conversation, separate from the user's messages.
Learn more: What is a System Prompt?
See also: Prompt

T

Temperature
A setting that controls randomness when a model picks the next token. Lower values give more predictable output; higher values give more varied output.
Learn more: What is a Large Language Model (LLM)? · How to Reduce AI Hallucinations
See also: Sampling
Token
The unit of text a model reads and writes: a word, part of a word, or punctuation. Limits and prices are commonly measured in tokens.
Learn more: What are Tokens in AI?
See also: Tokenizer · Context window
Tokenizer
The component that splits text into tokens and maps them to numbers. Different model families use different tokenizers.
Learn more: What are Tokens in AI?
See also: Token
Tool (agent tool)
A described capability, such as search, a database query or an API call, that a model can request and that your code executes.
Learn more: Agent Tools: How AI Agents Take Actions · Function Calling (Tool Calling) Explained
See also: Function calling · MCP
Training
The process of adjusting a model's parameters using data so its outputs improve on a target task.
Learn more: What is Artificial Intelligence? · What is Fine-Tuning an AI Model?
See also: Inference · Machine learning
Transformer
The neural-network architecture, introduced in 2017, behind most modern language models. Its key feature is attention.
Learn more: What is a Transformer? (Attention Explained)
See also: Attention · LLM

V

Vector
An ordered list of numbers. In AI, embeddings are vectors, and closeness between vectors reflects similarity in meaning.
Learn more: What are Embeddings in AI?
See also: Embedding · Cosine similarity
Vector database (vector store)
A system that stores embedding vectors with metadata and finds the closest matches to a query vector quickly.
Learn more: What is a Vector Database? · Vector Database vs Traditional Database
See also: Embedding · Approximate nearest neighbour (ANN)

Z

Zero-shot prompting
Asking a model to perform a task with instructions only and no examples.
Learn more: Prompt Engineering: How to Write Better AI Prompts
See also: Few-shot prompting
