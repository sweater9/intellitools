Object Detection and Image Segmentation

conceptfreshness: evolvingsources not yet verified

Object detection finds and labels things in an image with bounding boxes; segmentation labels them pixel by pixel. YOLO, Faster R-CNN, DETR and SAM are well-known approaches.

Short answer: Classification says what is in an image, detection says what and where (boxes), and segmentation outlines each region by pixels. Pick a one-stage detector (YOLO family) for speed, a two-stage or transformer model for accuracy, and judge results with IoU and mAP on your own data.

What is it?

A classifier looks at a photo and says "cat". An object detector draws a box around each cat, dog and car and names them. Segmentation goes further and traces the exact outline of each object. These are the building blocks behind self-checkout cameras, medical imaging tools, driver assistance and photo editors.

Also known as: object detection, YOLO, bounding boxes, bounding box, IoU, intersection over union, mAP, non-max suppression.

Technical definition

Detection predicts class labels and bounding boxes. Two-stage detectors (R-CNN family, Faster R-CNN; Ren et al., 2015) propose regions then classify them; one-stage detectors (YOLO, Redmon et al., 2015; SSD; RetinaNet) predict boxes densely in one pass; transformer detectors (DETR; Carion et al., 2020) use set prediction and avoid hand-built non-maximum suppression. Segmentation variants: semantic (class per pixel; U-Net, Ronneberger et al., 2015), instance (Mask R-CNN, He et al., 2017) and promptable segmentation (Segment Anything, Kirillov et al., 2023). Evaluation uses IoU (intersection over union) thresholds and mean average precision (mAP), commonly on COCO (Lin et al., 2014). Backbones are CNNs or vision transformers and are usually pre-trained and fine-tuned (Transfer Learning). Classical OpenCV pipelines (Haar cascades, HOG) still appear in simple or embedded settings.

When should I use it?

Use detection when you need locations and counts of objects, and segmentation when exact shape or area matters. For a single label per image use classification; for open-ended questions about a scene use a vision-language model.

Prerequisites and related concepts

Understand these first: Convolutional Neural Networks (CNNs), Transfer Learning.

Related concepts: Vision Transformers (ViT), CNN vs Vision Transformer, Vision-Language Models (VLMs), Embodied AI, Common Evaluation Metrics (Accuracy, F1, BLEU, ROUGE, Perplexity), AI Bias and Fairness, Document Understanding AI (OCR, Layout, Extraction).

Implementation patterns

  • Start from a pre-trained detector and fine-tune on a few hundred to a few thousand labelled images.
  • Use augmentation (scale, flip, colour, mosaic) and train/validation splits by scene, not by frame.
  • Tune the confidence and NMS (or equivalent) thresholds on a validation set for the precision/recall you need.
  • Export to ONNX or a vendor runtime and benchmark latency on the target device.
  • Use promptable segmentation for labelling help, then train a lightweight model.

Technologies and frameworks

Commonly associated: Ultralytics YOLO (check licence terms), torchvision detection models, Detectron2, MMDetection, OpenCV, Segment Anything, COCO and Pascal VOC datasets, ONNX Runtime / TensorRT for deployment. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Define the task (boxes, masks, or both) and the metric that matters (recall at a given precision, latency).
  2. Collect representative images and label them consistently with a guideline.
  3. Pick a pre-trained model sized for your latency budget and fine-tune it.
  4. Evaluate per class and per condition, not just overall mAP.
  5. Deploy with an optimised runtime and monitor drift in production.

Common failure modes

  • Small or distant objects missed because of input resolution or stride.
  • Class imbalance and sloppy labels dominating results.
  • Train/validation leakage from near-identical frames of the same video.
  • Accuracy collapsing under new lighting, cameras or viewpoints (domain shift).
  • Duplicate boxes from poorly tuned NMS, or merged boxes for crowded objects.
  • Overlooking licence terms of pre-trained weights and code.

Troubleshooting

  • Misses small objects — Increase input resolution, use multi-scale features or tiling, and check the smallest label sizes in your data.
  • Many false positives — Raise the confidence threshold, add hard-negative images, and review label quality.
  • Great validation mAP, poor in the field — Split by scene/camera, add field data, and test under realistic conditions.
  • Duplicate boxes — Tune NMS IoU threshold or use a model with end-to-end set prediction.

Contrasted with

  • Convolutional Neural Networks (CNNs) — CNNs are a model family; detection is a task that usually uses a CNN or transformer backbone.
  • Vision-Language Models (VLMs) — VLMs answer free-form questions about images; detectors return precise boxes for a fixed label set (open-vocabulary detectors blur this line).
