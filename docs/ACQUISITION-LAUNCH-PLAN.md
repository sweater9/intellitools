# IntelliTools — Acquisition Launch Pack

## Positioning
**IntelliTools — Less switching. More doing.**

Fast, focused everyday utilities in one workspace. No account friction, browser-first processing where possible, and direct tools for AI work, PDFs, images, text, privacy, productivity and everyday calculations.

## Primary launch goal
Acquire the first repeat users and learn which individual tools create organic search and referral demand. Optimize for useful feedback, return visits and tool-level traffic rather than vanity rankings.

## Product Hunt draft
**Name:** IntelliTools
**Tagline:** 40 focused everyday tools. One intelligent workspace.
**Short description:** IntelliTools brings practical browser-based utilities for AI prompts, PDFs, images, text, privacy, productivity and everyday work into one fast workspace. Open a tool, finish the task, and move on — with no account required.

**Maker comment draft:**
I built IntelliTools because small digital tasks kept sending me to different websites, accounts and workflows. The idea is simple: put genuinely useful everyday utilities in one consistent workspace and make the path from input to result as short as possible.

The current release has 40 tools covering AI work, PDFs, images, writing, privacy, developer tasks, productivity and everyday calculations. Many workflows are browser-first, and the site now remembers favourites and recently used tools locally so it becomes more useful when you return.

I would especially value feedback on two things: which tools you would actually bookmark, and what repetitive task is still missing.

## Community distribution principles
Do not mass-post the homepage. Find conversations where a specific tool directly solves the stated problem. Explain the solution first; disclose that IntelliTools is your product when linking it. Never manufacture comments, votes or testimonials.

### Conversation angles
- AI/prompt communities: structuring prompts; removing PII/secrets before sharing; checking generated claims against supplied evidence
- Developer communities: sanitizing cURL before sharing; JSON formatting; Base64/timestamp/slug utilities
- Freelancer/small-business communities: invoices, receipts and budgeting
- Privacy communities: local/browser-first utilities, PII redaction, tracking-parameter inspection
- Productivity communities: focus timer, habit journal, decision matrix and deadline planning

## 30-day acquisition sequence
**Week 1 — Indexing and baseline**
Submit sitemap in Google Search Console, inspect the homepage and priority landing pages, and record baseline impressions/clicks.

**Week 2 — Problem-led distribution**
Share individual tools only in relevant conversations. Track which pages earn visits and repeat use.

**Week 3 — Product Hunt preparation**
Finalize thumbnail/screenshots/demo, polish maker profile, schedule the launch, and prepare the first comment.

**Week 4 — Launch and learn**
Launch, respond personally to feedback, record requested tools, and prioritize the pages/tools that produce meaningful usage.

## Measurement
Review weekly:
- Search impressions and clicks by landing page
- Queries generating impressions
- Top entry tool pages
- Referral sources
- Which tools users favourite
- Which tools appear in Recently Used
- Product Hunt visits and qualitative feedback

Avoid optimizing for raw pageviews alone. The core signal is whether a visitor solves a task and returns for another one.
